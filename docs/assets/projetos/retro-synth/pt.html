Sintetizador Web Polifônico

O RetroSynth explora o poder de processamento de áudio em tempo real com a Web Audio API e nós de áudio nativos do navegador. Permite desenhar formas de onda personalizadas, encadear modulações FM (Frequency Modulation) e gravar loops diretamente no navegador.

Recursos Principais

  • 8 vozes de polifonia independentes com envelopes ADSR individuais.
  • Filtro passa-baixa ressonante com saturação emulando circuitos analógicos vintage.
  • Conexão instantânea com teclados e controladores USB através da Web MIDI API.
  • Exportação de faixas em formato WAV em tempo real sem perdas.
