Web Polyphonic Synthesizer

RetroSynth harnesses real-time browser audio digital signal processing with the Web Audio API and custom audio worklets. Enables sound designers to sculpt custom waveforms, chain Frequency Modulation operators, and export studio-grade audio loops without third-party plugins.

Key Features

  • 8-voice polyphony with dedicated ADSR envelope generators per voice.
  • Resonant low-pass ladder filter emulation with warm analog-style saturation.
  • Plug-and-play USB hardware synth controller support via the Web MIDI API.
  • Real-time lossless 24-bit WAV file rendering and export.
