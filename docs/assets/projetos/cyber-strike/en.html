About the Project

Cyber Strike: Neon Protocol is an arcade tactical space combat simulator featuring a retro cyberpunk aesthetic. Engineered to run natively in modern web browsers with zero external plugins or heavy engines, delivering a rock-solid 60 FPS experience even on mobile and mid-tier laptops.

Key Features & Highlights

  • Custom WebGL Pipeline: Bespoke post-processing shaders for bloom, chromatic aberration, and optional CRT scanlines.
  • Adaptive Audio Engine: Powered by the Web Audio API with procedurally synthesized sound effects for laser blasts, shields, and explosions.
  • Arcade Physics Engine: Vector SAT (Separating Axis Theorem) collision detection and particle trails with velocity damping.
  • Gamepad & Keyboard Controls: Seamless plug-and-play support for standard controllers and responsive keyboard/mouse mapping.

Tech Stack

Built using TypeScript, WebGL 2.0, GLSL Shaders, Web Audio API, and an internal Entity Component System (ECS) architecture designed for high projectile counts.

Engineering Highlights

The primary challenge was keeping draw calls to an absolute minimum during bullet-hell patterns. By implementing GPU instanced mesh rendering, the game easily manages over 2,000 active particles with negligible CPU overhead.
