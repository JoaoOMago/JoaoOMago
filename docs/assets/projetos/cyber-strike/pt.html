Sobre o Projeto

Cyber Strike: Neon Protocol é um simulador de combate tático espacial arcade com estética cyberpunk retrô. Projetado para rodar diretamente nos navegadores modernos sem plugins adicionais ou dependências pesadas, atingindo sólidos 60 quadros por segundo mesmo em dispositivos intermediários.

Destaques e Funcionalidades

  • Pipeline WebGL Customizado: Shaders de pós-processamento para efeito de bloom, aberração cromática e linhas de scan CRT opcionais.
  • Trilha Sonora e Efeitos de Áudio Dinâmicos: Implementado via Web Audio API com sintetizadores sintetizados proceduralmente para lasers e explosões.
  • Sistema de Física Arcade: Colisões vetoriais SAT (Separating Axis Theorem) e partículas com aceleração contínua.
  • Suporte a Controles: Totalmente jogável via Teclado/Mouse ou Gamepads compatíveis (Xbox, DualShock).

Tecnologias Utilizadas

Construído utilizando TypeScript, WebGL 2.0, GLSL Shaders, Web Audio API e arquitetura modular ECS (Entity Component System) para escalabilidade dos inimigos e projéteis.

Desafios de Engenharia

O principal desafio foi manter a contagem de draw calls baixa em momentos de chuva de projéteis. Isso foi resolvido através de instanced mesh rendering, permitindo mais de 2.000 partículas ativas simultâneas com baixo uso de CPU.
